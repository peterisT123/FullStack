# Full Stack Programming Lectures

This repository contains Jupyter notebooks for full-stack programming lectures.

## Automatic Publishing

The notebooks in this repository are automatically converted to HTML and published to [peterisT123.github.io](https://peterisT123.github.io) whenever changes are pushed to the main branch.

### Setup Requirements

To enable automatic publishing, you need to:

1. Create a Personal Access Token (PAT) in GitHub with `repo` permissions
2. Add the token as a secret named `PAGES_DEPLOY_TOKEN` in this repository's settings

### Manual Publishing

You can also trigger the publishing workflow manually from the Actions tab.
